# 📟문자열 덧셈 계산기
## ⚙️ 기능 목록 구현

### 1. 덧셈 안내문 출력
- `"덧셈할 문자열을 입력해 주세요."` 출력 

### 2. 문자열 입력받기
- 구분자와 양수로 구성된 문자열 입력받기
- 기본 구분자
  - `쉼표(,)` 또는 `콜론(:)`을 기준으로 구분
- 커스텀 구분자
  - 기본 구준자 외에 다른 구분자로 커스텀 구분자로 지정
  - `"//"`와 `"\n"` 사이에 위치하는 문자를 커스텀 구분자로 사용
- 잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시킨 후 종료

### 3. 덧셈 기능 구현
- 구분자를 기준으로 나눈 숫자들을 합산

### 4. 덧셈 결과 출력
- `"결과 : "`와 함께 합계 출력
